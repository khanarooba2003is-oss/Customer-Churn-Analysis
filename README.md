Project Overview
This project analyzes customer churn patterns in European Banking using customer segmentation and Power BI dashboarding.

Tools Used
Python
Google Colab
Pandas
Power BI
Matplotlib
Seaborn
Key Findings
Overall Churn Rate: 20.37%
Germany recorded the highest churn rate (32.44%)
Customers aged 46–60 showed the highest churn (51.12%)
Inactive customers churned nearly twice as much as active customers
Low balance customers showed the highest churn risk
